# Vcenter.Automation.OpenApi.Model.VcenterNamespaceManagementVirtualMachineClassesConfigStatus
ConfigStatus represents the config status of the VM class.  Possible values:   - `READY`: Indicates that the instance of the Vcenter.NamespaceManagement.VirtualMachineClasses is ready to be used.   - `REMOVING`: Indicates that the instance of the Vcenter.NamespaceManagement.VirtualMachineClasses is being deleted. At this state the VM class cannot be associated with new Namespace.   This enumeration was added in __vSphere API 7.0.2.00100__.
