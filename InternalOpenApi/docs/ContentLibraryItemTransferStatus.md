# Vcenter.Automation.OpenApi.Model.ContentLibraryItemTransferStatus
The Content.Library.Item.TransferStatus enumerated type defines the transfer state of a file.  Possible values:   - `WAITING_FOR_TRANSFER`: Indicates that a file has been defined for a library item and its content needs to be uploaded.   - `TRANSFERRING`: Indicates that data is being transferred to the file.   - `READY`: Indicates that the file has been fully transferred and is ready to be used.   - `VALIDATING`: Indicates that the file is being validated (checksum, type adapters).   - `ERROR`: Indicates that there was an error transferring or validating the file.
