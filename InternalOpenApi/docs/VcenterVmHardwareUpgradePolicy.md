# Vcenter.Automation.OpenApi.Model.VcenterVmHardwareUpgradePolicy
The Vcenter.Vm.Hardware.UpgradePolicy enumerated type defines the valid virtual hardware upgrade policies for a virtual machine.  Possible values:   - `NEVER`: Do not upgrade the virtual machine when it is powered on.   - `AFTER_CLEAN_SHUTDOWN`: Run scheduled upgrade when the virtual machine is powered on after a clean shutdown of the guest operating system.   - `ALWAYS`: Run scheduled upgrade when the virtual machine is powered on.
