# Vcenter.Automation.OpenApi.Model.CisTaskStatus
The Cis.Task.Status enumerated type defines the status values that can be reported for an operation.  Possible values:   - `PENDING`: The operation is in pending state.   - `RUNNING`: The operation is in progress.   - `BLOCKED`: The operation is blocked.   - `SUCCEEDED`: The operation completed successfully.   - `FAILED`: The operation failed.   This enumeration was added in __vSphere API 6.7__.
