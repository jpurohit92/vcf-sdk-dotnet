# Vcenter.Automation.OpenApi.Model.VapiStdErrorsConcurrentChange
The Vapi.Std.Errors.ConcurrentChange error indicates that a data structure, entity, or resource has been modified since some earlier point in time. Typically this happens when the client is doing the *write* portion of a read-modify-write sequence and indicates that it wants the server to notify it if the data in the server has changed after it did the *read*, so that it can avoid overwriting that change inadvertantly.
