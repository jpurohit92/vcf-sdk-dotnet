# Vcenter.Automation.OpenApi.Model.VcenterVmHardwareAdapterScsiSharing
The Vcenter.Vm.Hardware.Adapter.Scsi.Sharing enumerated type defines the valid bus sharing modes for a virtual SCSI adapter.  Possible values:   - `NONE`: The virtual SCSI bus is not shared.   - `VIRTUAL`: The virtual SCSI bus is shared between two or more virtual machines. In this case, no physical machine is involved.   - `PHYSICAL`: The virtual SCSI bus is shared between two or more virtual machines residing on different physical hosts.
