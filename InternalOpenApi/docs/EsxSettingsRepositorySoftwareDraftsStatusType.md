# Vcenter.Automation.OpenApi.Model.EsxSettingsRepositorySoftwareDraftsStatusType
The Esx.Settings.Repository.Software.Drafts.StatusType enumerated type defines possible values of status of a software draft. A draft is invalid if a newer version of the original software specification has been committed since this draft was created.  Possible values:   - `VALID`: Software draft is valid.   - `INVALID`: Software draft is invalid.   This enumeration was added in __vSphere API 9.0.0.0__.
