# Vcenter.Automation.OpenApi.Model.EsxSettingsClusterLivePatchActionLivePatchMode
The Esx.Settings.ClusterLivePatchAction.LivePatchMode enumerated type contains the possible Live Patch modes for remediating hosts.  Possible values:   - `DISABLE_LIVE_PATCH`: Disable Live Patch.   - `AUTO_LIVE_PATCH`: Perform Live Patch when possible. Use full maintenance mode for hosts that cannot perform Live Patch.   - `ENFORCE_LIVE_PATCH`: Enforce Live Patch. Disallow remediation if there is a host that cannot perform Live Patch.   This enumeration was added in __vSphere API 9.1.0.0__.
