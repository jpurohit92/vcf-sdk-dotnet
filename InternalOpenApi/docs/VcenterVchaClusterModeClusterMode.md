# Vcenter.Automation.OpenApi.Model.VcenterVchaClusterModeClusterMode
The Vcenter.Vcha.Cluster.Mode.ClusterMode enumerated type defines the possible modes for a VCHA Cluster.  Possible values:   - `ENABLED`: VCHA Cluster is enabled. State replication between the Active and Passive node is enabled and automatic failover is allowed.   - `DISABLED`: VCHA Cluster is disabled. State replication between the Active and Passive node is disabled and automatic failover is not allowed.   - `MAINTENANCE`: VCHA Cluster is in maintenance mode. State replication between the and Passive node is enabled but automatic failover is not allowed.   This enumeration was added in __vSphere API 6.7.1__.
