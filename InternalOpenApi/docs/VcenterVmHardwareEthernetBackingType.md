# Vcenter.Automation.OpenApi.Model.VcenterVmHardwareEthernetBackingType
The Vcenter.Vm.Hardware.Ethernet.BackingType enumerated type defines the valid backing types for a virtual Ethernet adapter.  Possible values:   - `STANDARD_PORTGROUP`: vSphere standard portgroup network backing.   - `HOST_DEVICE`: Legacy host device network backing. Imported VMs may have virtual Ethernet adapters with this type of backing, but this type of backing cannot be used to create or to update a virtual Ethernet adapter.   - `DISTRIBUTED_PORTGROUP`: Distributed virtual switch backing.   - `OPAQUE_NETWORK`: Opaque network backing.
