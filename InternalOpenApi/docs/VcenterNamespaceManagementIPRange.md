# Vcenter.Automation.OpenApi.Model.VcenterNamespaceManagementIPRange
The Vcenter.NamespaceManagement.IPRange schema is used to express a range of IP addresses. The formats supported by this structure will depend on the IP addressing scheme that is being used by vSphere Namespaces. Currently, vSphere Namespaces only supports IPv4.
