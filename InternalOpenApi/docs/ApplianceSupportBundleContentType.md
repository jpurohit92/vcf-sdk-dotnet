# Vcenter.Automation.OpenApi.Model.ApplianceSupportBundleContentType
The Appliance.SupportBundle.ContentType enumerated type defines the content in the support bundle generated.  Possible values:   - `LOGS`: Support bundle will contain only logs.   - `CORES`: Support bundle will contain only core files.   - `ALL`: Support bundle will contain logs and core files. By default logs and cores are collected.   This enumeration was added in __vSphere API 8.0.2.0__.
