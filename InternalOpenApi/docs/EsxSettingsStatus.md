# Vcenter.Automation.OpenApi.Model.EsxSettingsStatus
The Esx.Settings.Status enumerated type defines the status result for a particular check.  Possible values:   - `OK`: The check indicates a success.   - `WARNING`: The check indicates a warning.   - `TIMEOUT`: The check did not return in a timely manner.   - `ERROR`: The check indicates an error.   - `RETRY`: The check failed because of an intermittent error, for example a service is overloaded. The client can choose to retry the health check before considering the check as failed.
