# Vcenter.Automation.OpenApi.Model.VcenterContentRegistriesRecurrence
The Vcenter.Content.Registries.Recurrence enumerated type defines the supported values for how often to run a specific operation for a container registry.  Possible values:   - `NONE`: No operation is scheduled.   - `DAILY`: An operation occurs on a daily basis.   - `WEEKLY`: An operation occurs on a weekly basis.   This enumeration was added in __vSphere API 7.0.0.0__.
