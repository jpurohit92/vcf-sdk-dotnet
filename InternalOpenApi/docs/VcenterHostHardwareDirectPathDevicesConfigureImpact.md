# Vcenter.Automation.OpenApi.Model.VcenterHostHardwareDirectPathDevicesConfigureImpact
The Vcenter.Host.Hardware.DirectPathDevices.ConfigureImpact schema provides the different side effects of a DirectPath device reconfiguration.  Possible values:   - `NONE`: No impact to the host or any virtual machines.   - `HOST_MAINTENANCE_MODE_REQUIRED`: Host needs to go through maintenance mode for the desired configuration changes to take effect.   - `HOST_REBOOT_REQUIRED`: Host needs to be rebooted for the desired configuration changes to take effect.   This enumeration was added in __vSphere API 9.1.0.0__.
