# Vcenter.Automation.OpenApi.Model.EsxSettingsDepotsOfflineSourceType
The Esx.Settings.Depots.Offline.SourceType enumerated type defines possible values of sources for the offline depot.  Possible values:   - `PULL`: Content is pulled from the URL location. The URL scheme of the value in {@link CreateSpec#location) can be http, https or file.   - `PUSH`: Content was previously uploaded using the file upload endpoint present on vCenter appliance. This endpoint is present at https://VCENTERFQDN:9087/vum-fileupload URL.   This enumeration was added in __vSphere API 7.0.0.0__.
