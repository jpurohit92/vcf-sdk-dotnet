# Vcenter.Automation.OpenApi.Model.ContentLibraryModelLibraryType
The Content.LibraryModel.LibraryType enumerated type defines the type of a *Content.LibraryModel*.    The type of a library can be used to determine which additional services can be performed with a library.  Possible values:   - `LOCAL`: The library contents are defined and stored by the local Content Library Service installation.    A local library can be retrieved and managed via the *Content.LocalLibrary*.   - `SUBSCRIBED`: The library synchronizes its items and content from another published library.    A subscribed library can be retrieved and managed via the *Content.SubscribedLibrary*.
