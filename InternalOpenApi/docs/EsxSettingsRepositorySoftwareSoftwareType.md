# Vcenter.Automation.OpenApi.Model.EsxSettingsRepositorySoftwareSoftwareType
The Esx.Settings.Repository.Software.SoftwareType enumerated type describes whether a software specification is Single or Composite.  Possible values:   - `SINGLE`: A software specification of this type contains only one image (default image).   - `COMPOSITE`: A software specification of this type contains one default image and one or more alternative images.   This enumeration was added in __vSphere API 9.0.0.0__.
