# Vcenter.Automation.OpenApi.Model.VcenterServicesServiceState
The Vcenter.Services.Service.State enumerated type defines valid Run State for services.  Possible values:   - `STARTING`: Service Run State is Starting, it is still not functional   - `STOPPING`: Service Run State is Stopping, it is not functional   - `STARTED`: Service Run State is Started, it is fully functional   - `STOPPED`: Service Run State is Stopped   This enumeration was added in __vSphere API 6.7__.
