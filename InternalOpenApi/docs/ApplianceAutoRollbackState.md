# Vcenter.Automation.OpenApi.Model.ApplianceAutoRollbackState
The Appliance.AutoRollbackState enumerated type defines the sub status that can be reported for the auto rollback state during failed operation.  Possible values:   - `ROLLBACK_NOT_STARTED`: The auto rollback is not started yet.   - `ROLLBACK_IN_PROGRESS`: The auto rollback is in progress.   - `ROLLBACK_SUCCEEDED`: The auto rollback is successful.   - `ROLLBACK_FAILED`: The auto rollback is failed.
