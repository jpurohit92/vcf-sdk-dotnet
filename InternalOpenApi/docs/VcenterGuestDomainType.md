# Vcenter.Automation.OpenApi.Model.VcenterGuestDomainType
The Vcenter.Guest.Domain.Type enumerated type defines the types of network the virtual machine should join to after the customization is completed.  Possible values:   - `WORKGROUP`: The virtual machine should be be joined to a workgroup.   - `DOMAIN`: The virtual machine should be be joined to a domain.
