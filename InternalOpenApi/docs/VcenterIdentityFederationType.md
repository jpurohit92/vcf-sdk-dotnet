# Vcenter.Automation.OpenApi.Model.VcenterIdentityFederationType
The Vcenter.Identity.FederationType enumerated type contains the possible types of federation paths for, vCenter Server identity providers configuration.  Possible values:   - `DIRECT_FEDERATION`: vCenter Server federated directly to the external identity provider.   - `INDIRECT_FEDERATION`: vCenter Server federated indirectly to the external identity provider, by means of an intermediary federation broker.   - `VMWARE_SSO_FEDERATION`: vCenter Server federated by VMWARE SSO  This constant was added in __vSphere API 9.0.0.0__.
