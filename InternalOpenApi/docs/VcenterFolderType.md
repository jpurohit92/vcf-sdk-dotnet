# Vcenter.Automation.OpenApi.Model.VcenterFolderType
The Vcenter.Folder.Type enumerated type defines the type of a vCenter Server folder. The type of a folder determines what what kinds of children can be contained in the folder.  Possible values:   - `DATACENTER`: A folder that can contain datacenters.   - `DATASTORE`: A folder that can contain datastores.   - `HOST`: A folder that can contain compute resources (hosts and clusters).   - `NETWORK`: A folder that can contain networkds.   - `VIRTUAL_MACHINE`: A folder that can contain virtual machines.
