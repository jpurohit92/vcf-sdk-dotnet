# Vcenter.Automation.OpenApi.Model.VcenterDeploymentHistoryMigrationOption
The Vcenter.Deployment.HistoryMigrationOption enumerated type defines the vCenter history migration option choices.  Possible values:   - `EVENTS_TASKS`: Only event data and task data will be migrated along with the core data.   - `ALL`: All history data will be migrated along with the core data.
