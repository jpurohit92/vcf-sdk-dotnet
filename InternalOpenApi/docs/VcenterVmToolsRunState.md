# Vcenter.Automation.OpenApi.Model.VcenterVmToolsRunState
Current run state of VMware Tools in the guest operating system.  Possible values:   - `NOT_RUNNING`: VMware Tools is not running.   - `RUNNING`: VMware Tools is running.   - `EXECUTING_SCRIPTS`: VMware Tools is running scripts as part of a state transition.   This enumeration was added in __vSphere API 7.0.0.0__.
