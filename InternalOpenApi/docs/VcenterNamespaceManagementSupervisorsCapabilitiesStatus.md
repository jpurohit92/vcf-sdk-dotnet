# Vcenter.Automation.OpenApi.Model.VcenterNamespaceManagementSupervisorsCapabilitiesStatus
The Vcenter.NamespaceManagement.Supervisors.Capabilities.Status enumerated type represents the activation state of the Supervisor capability with the current infrastructure.  Possible values:   - `SUPPORTED`: The capability is supported on the Supervisor.   - `SUPPORTED_NOT_ACTIVATED`: The capability is supported on the Supervisor but is not activated. The *Vcenter.NamespaceManagement.Supervisors.Capabilities.Capability.messages* field will describe the reason.   - `UNSUPPORTED`: The capability is not supported on the Supervisor.   This enumeration was added in __vSphere API 9.1.0.0__.
