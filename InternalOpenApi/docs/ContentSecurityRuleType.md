# Vcenter.Automation.OpenApi.Model.ContentSecurityRuleType
The Content.SecurityRuleType enumerated type defines the security rules which can be applied to different item types.  Possible values:   - `OVF_STRICT_VERIFICATION`: This rule indicates that an OVF/OVA item can only be imported or synced to a content library if its certificate is valid and signed by a trusted CA.   This enumeration was added in __vSphere API 7.0.3.0__.
