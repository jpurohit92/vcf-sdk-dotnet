# Vcenter.Automation.OpenApi.Model.VcenterCapacityUsageSeverity
The Vcenter.Capacity.Usage.Severity enumerated type represents the severity of a configuration's usage, indicating whether it's within limits, exceeds a threshold, or exceeds the maximum.  Possible values:   - `NORMAL`: The configuration's current usage is within the defined threshold.   - `THRESHOLD_EXCEEDED`: The configuration's current usage has exceeded the defined threshold.   - `MAXIMUM_EXCEEDED`: The configuration's current usage has exceeded the maximum recommended value.   This enumeration was added in __vSphere API 9.1.0.0__.
