# Vcenter.Automation.OpenApi.Model.VcenterHostCreateSpecThumbprintVerification
The Vcenter.Host.CreateSpec.ThumbprintVerification enumerated type defines the thumbprint verification schemes for a host's SSL certificate.  Possible values:   - `NONE`: Accept the host's thumbprint without verifying it.   - `THUMBPRINT`: Host's SSL certificate verified by checking its thumbprint against the specified thumbprint.   - `CERTIFICATE`: Host's SSL certificate verified by checking it against the provided PEM SSL certificate.  This constant was added in __vSphere API 9.0.0.0__.
