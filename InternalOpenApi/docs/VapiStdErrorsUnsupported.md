# Vcenter.Automation.OpenApi.Model.VapiStdErrorsUnsupported
The Vapi.Std.Errors.Unsupported error indicates that the operation is not supported by the resource.    Examples:     - Trying to hot-plug a CPU when the current configuration of the VM does not support hot-plugging of CPUs.     - Trying to change the memory size to a value that is not within the acceptable guest memory bounds supported by the virtual machine's host.
