# Vcenter.Automation.OpenApi.Model.EsxSettingsImageCustomizationAction
The Esx.Settings.ImageCustomizationAction enumerated type contains the different possible types of image customization status. It will be set only when the desired image is customized by the user.  Possible values:   - `RETAINED`: The component is retained at an older version in the desired software specification.   - `REMOVED`: The component is removed by the user in the desired software specification.   This enumeration was added in __vSphere API 8.0.3.0__.
