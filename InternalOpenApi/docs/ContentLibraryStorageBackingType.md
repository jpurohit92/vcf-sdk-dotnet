# Vcenter.Automation.OpenApi.Model.ContentLibraryStorageBackingType
The Content.Library.StorageBacking.Type enumerated type specifies the type of the *Content.Library.StorageBacking*.  Possible values:   - `DATASTORE`: The content of the library will be stored on a datastore.    These are vCenter Server managed datastores, and are logical containers that hide specifics of each storage device. Depending on the type of storage you use, datastores can be backed by the following file system formats:       -  Virtual Machine File System (VMFS)       -  Network File System (NFS)         - `OTHER`: The content of the library will be stored on a remote file system.    Supports the following remote file systems:       -  NFS (on vCenter Server Appliance)       -  SMB (on vCenter Server Appliance and vCenter Server for Windows)
