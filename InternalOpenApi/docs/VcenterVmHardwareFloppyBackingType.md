The Vcenter.Vm.Hardware.Floppy.BackingType enumerated type defines the valid backing types for a virtual floppy drive.  Possible values:   - `IMAGE_FILE`: Virtual floppy drive is backed by an image file.   - `HOST_DEVICE`: Virtual floppy drive is backed by a device on the host where the virtual machine is running.   - `CLIENT_DEVICE`: Virtual floppy drive is backed by a device on the client that is connected to the virtual machine console.
