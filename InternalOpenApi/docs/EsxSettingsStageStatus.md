# Vcenter.Automation.OpenApi.Model.EsxSettingsStageStatus
The Esx.Settings.StageStatus enumerated type contains the possible different staged statuses with respect to target version. This is only relevant when the value of ComplianceStatus is *Esx.Settings.ComplianceStatus.NON_COMPLIANT*.  Possible values:   - `STAGED`: Required components/payloads are already staged.   - `NOT_STAGED`: Required components/payloads are not staged.   - `UNKNOWN`: Required components/payloads staged status is unknown.
