# Vcenter.Automation.OpenApi.Model.ContentLibraryItemUpdateSessionModelState
The state of an update session.  Possible values:   - `ACTIVE`: The session is currently active. This is the initial state when the session is created. Files may be uploaded by the client or pulled by the Content Library Service at this stage.   - `DONE`: The session is done and all its effects are now visible.   - `ERROR`: There was an error during the session.   - `CANCELED`: The session has been canceled.
