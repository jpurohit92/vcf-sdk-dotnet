# Vcenter.Automation.OpenApi.Model.VcenterNamespacesManagementServicesAccessGrantsWorkloadType
The Vcenter.Namespaces.ManagementServices.AccessGrants.WorkloadType enumerated type enumerates the types of workloads which could be made the recipient of an Access Grant.  Possible values:   - `VIRTUAL_MACHINE`: Scope grant to Virtual Machines managed by VM Service.   - `VSPHERE_POD`: Scope grant to vSphere Pods.   - `ANY`: Scope grant to any type of workloads in the namespace. Note that ANY WorkloadType evaluates to workloads of any current and future WorkloadTypes.   This enumeration was added in __vSphere API 9.1.0.0__.
