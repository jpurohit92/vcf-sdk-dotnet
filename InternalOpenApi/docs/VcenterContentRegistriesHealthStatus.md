# Vcenter.Automation.OpenApi.Model.VcenterContentRegistriesHealthStatus
The Vcenter.Content.Registries.Health.Status enumerated type describes the status of the container registry.  Possible values:   - `STARTING`: Container registry is starting.   - `RUNNING`: Container registry is running.   - `WARNING`: Container registry is running with some warning, for example, storage reaches the threshold configuration.   - `ERROR`: Container registry failed to start or stopped with fatal error.   - `DELETING`: Container registry is being deleted.   This enumeration was added in __vSphere API 7.0.0.0__.
