# Vcenter.Automation.OpenApi.Model.VcenterGuestIpv6Type
The Vcenter.Guest.Ipv6.Type enumerated type specifies different types of the IPv6 configuration.  Possible values:   - `DHCP`: DHCP IPv6 configuration.   - `STATIC`: Static IPv6 configuration.   - `USER_INPUT_REQUIRED`: Indicates that the IPv6 settings are not specified in advance. The user must provide a valid value when the actual customization spec is applied to a virtual machine.   This enumeration was added in __vSphere API 7.0.0.0__.
