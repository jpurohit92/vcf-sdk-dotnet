# Vcenter.Automation.OpenApi.Model.VcenterGuestWindowsNetworkAdapterSettingsNetBIOSMode
The Vcenter.Guest.WindowsNetworkAdapterSettings.NetBIOSMode enumerated type specifies different NetBIOS settings for Windows guest operating systems.  Possible values:   - `USE_DHCP`: DHCP server decides whether or not to use NetBIOS.   - `ENABLE`: Always use NetBIOS.   - `DISABLE`: Never use NetBIOS.   This enumeration was added in __vSphere API 7.0.0.0__.
