# Vcenter.ViJson.OpenApi.Model.VsanPerfSummaryTypeEnum
Stats summarization types indicate how multiple samples of a specific metric are transformed or aggregated into a single statistical value.  Valid types are:  Possible values: - `average`: The actual value collected or the average of all values collected during the summary period. - `maximum`: The maximum value of the performance metric value over the summarization period. - `minimum`: The minimum value of the performance metric value over the summarization period. - `latest`: The most recent value of the performance metric over the summarization period. - `summation`: The sum of all the values of the performance metric over the summarization period. - `none`: The counter is never rolled up. - `VsanPerfSummaryType_Unknown`
