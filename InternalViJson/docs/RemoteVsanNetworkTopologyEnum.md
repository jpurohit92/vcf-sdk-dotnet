# Vcenter.ViJson.OpenApi.Model.RemoteVsanNetworkTopologyEnum
Network topology between the client and server cluster in a HCI Mesh configuration.  Possible values: - `Topology_Unknown`: Represent the value when the lower version client cannot recognize the enum value. - `Symmetric`: Hosts in client and server clusters have homogenous network connectivity with similar network properties like bandwidth and latency. - `Asymmetric`: Hosts in the client cluster have asymmetric network connectivity with different server cluster sites, such that hosts in a client site have a high bandwidth low latency link to one server site and a low bandwidth high lantency link to the other server site.
