# Vcenter.ViJson.OpenApi.Model.TooManyGuestLogons
A TooManyGuestLogons exception is thrown when there are too many concurrent login sessions active in the guest.  *GuestAuthManager.ReleaseCredentialsInGuest* can be called on ticketed sessions that are no longer needed. This will decrease the number of concurrent sessions active in the guest.
