# Vcenter.ViJson.OpenApi.Model.NoAgentVmNetwork
An agent virtual machine is expected to be deployed on a host, but the agent cannot be deployed because the agent network has not been configured on the host.  This is a passive remediable issue. The administrator must configure the agent virtual machine network on the host.  This structure may be used only with operations rendered under `/eam`.
