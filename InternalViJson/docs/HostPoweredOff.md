# Vcenter.ViJson.OpenApi.Model.HostPoweredOff
Deprecated hostPoweredOff will no longer be used, instead *ManagedHostNotReachable* will be raised.  An agent virtual machine is expected to be removed from a host, but the agent virtual machine has not been removed.  The reason is that the host is powered off.  This is not a remediable issue. To remediate, power on the host.  This structure may be used only with operations rendered under `/eam`.
