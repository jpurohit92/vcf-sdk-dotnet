# Vcenter.ViJson.OpenApi.Model.CnsFileCreateSpec
Specification for file volume creation.  The file volume could be NFS or SMB file share. Currently, only NFS file shares provisioned by vSAN file service will be supported. CNS may support non NFS, non vSAN file service based file shares in future.  This structure may be used only with operations rendered under `/vsan`.
