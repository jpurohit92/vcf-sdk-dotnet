# Vcenter.ViJson.OpenApi.Model.CnsClusterTypeEnum
Enumerates types of container orchestrator cluster for which volume operations are being performed.     This is a list of supported container orchestrator cluster types. Also the ClusterType value can be used to list all the volumes that exist for the specified type of container orchestrator.  Possible values: - `KUBERNETES`: for container orchestrator cluster of type Kubernetes. - `ClusterType_Unknown`: represent the value when the lower version client cannot recognize the enum value.
