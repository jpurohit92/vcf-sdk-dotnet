# Vcenter.ViJson.OpenApi.Model.VpCategoryEnum
A Category to indicate whether provider is of internal or external category.  This classification can help selectively enable few administrative functions such as say unregistration of a provider.  Possible values: - `internal`: An internal provider category indicates the set of providers such as IOFILTERS and VSAN. - `external`: An external provider category indicates the set of providers are external and not belong   to say either of IOFILTERS or VSAN category.
