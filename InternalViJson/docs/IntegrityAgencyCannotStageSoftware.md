# Vcenter.ViJson.OpenApi.Model.IntegrityAgencyCannotStageSoftware
Deprecated as of vSphere 9.0. Please refer to vLCM Image APIs.  The software defined by an Agency cannot be staged in VUM.  The staging operation consists of the following steps: - Upload the Agency software (VIBs) to the VUM depot. - Create or update a VUM Baseline with the Agency software and scope.    This is an active remediable issue. To remediate, vSphere ESX Agent Manager retries the stage operation.  This structure may be used only with operations rendered under `/eam`.
