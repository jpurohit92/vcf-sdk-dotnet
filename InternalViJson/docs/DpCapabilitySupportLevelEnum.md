# Vcenter.ViJson.OpenApi.Model.DpCapabilitySupportLevelEnum
Enumeration of the support level for a cluster in terms of vSphere Data Protection capabilities.  Possible values: - `supported`: The capability is supported on all hosts in the cluster. - `partially_supported`: The capability is supported on only some but not all of the hosts in the cluster. - `not_supported`: The capability is not supported on any of the hosts in the cluster. - `CapabilitySupportLevel_unknown`: Fallback value for an unknown CapabilitySupportLevel seen by a client.    ***Since:*** 8.0.0.4
