# Vcenter.ViJson.OpenApi.Model.AgencyVMPlacementPolicyVMAntiAffinityEnum
Deprecated as of vSphere 9.0. Please refer to vLCM System VMs APIs.  Defines if the deployed VMs needs to run on different hosts.  Possible values: - `none`: Denotes no specific VM anti-affinity policy. - `soft`: Best effort is made the VMs to run on different hosts as long as   this does not impact the ability of the host to satisfy current CPU   or memory requirements for virtual machines on the system.      NOTE: Currently not supported - i.e. the agency configuration is   considered as invalid.
