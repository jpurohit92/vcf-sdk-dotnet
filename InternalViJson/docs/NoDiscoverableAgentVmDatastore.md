# Vcenter.ViJson.OpenApi.Model.NoDiscoverableAgentVmDatastore
Deprecated as of vSphere 9.0. No longer in use since vCLS 2.0.  An agent virtual machine is expected to be deployed on a host, but the agent cannot be deployed because the agent VM datastore could not be discovered, as per defined selection policy, on the host.  This issue can be remediated passively if the administrator configures new datastores on the host.  This structure may be used only with operations rendered under `/eam`.
