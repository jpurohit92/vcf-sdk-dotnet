# Vcenter.ViJson.OpenApi.Model.VsanHealthThresholdTargetEnum
The vSAN threshold target type.  it is used in *VsanHealthThreshold*, to indicate the thresholds are applied on which target. A target could be a part of one health check, or just one entire health check. For below targets, a valid threshold should be a percentage, e.g., an integer value which is in range \\[0, 100\\].  Possible values: - `diskspace_vsan_datastore`: The vSAN datastore part of \"Disk space\" - `diskspace_vsan_direct`: The vSAN direct part of \"Disk space\" - `diskspace_vsan_pmem` - `VsanHealthThresholdTarget_Unknown`
