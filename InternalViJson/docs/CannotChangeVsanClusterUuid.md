# Vcenter.ViJson.OpenApi.Model.CannotChangeVsanClusterUuid
Fault thrown for cases that a VSAN cluster UUID may not be changed.  For example, the VSAN cluster UUID for a host may not be changed so long as that host is enabled for VSAN. The VSAN cluster UUID for a given *ClusterComputeResource* may not be changed so long as that vim.ClusterComputeResource is enabled for VSAN.  See also *HostVsanSystem.UpdateVsan_Task*, *ComputeResource.ReconfigureComputeResource_Task*.
