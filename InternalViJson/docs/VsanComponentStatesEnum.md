# Vcenter.ViJson.OpenApi.Model.VsanComponentStatesEnum
vSAN component state types.  Possible values: - `ACTIVE`: The component is in a normal active state. - `ACTIVE_STALE`: The component is in a normal state but the component   is not in sync with the vSAN cluster. - `ABSENT`: The component is absent. - `ABSENT_RESYNC`: The component is absent, and there are some bytes need   to be synced for this component. - `DEGRADED`: The component is in degraded state. - `RECONFIG`: The component is in reconfiguration state. - `UNKNOWN`: The component state is unknown.
