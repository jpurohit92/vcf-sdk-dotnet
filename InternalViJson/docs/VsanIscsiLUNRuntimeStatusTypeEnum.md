# Vcenter.ViJson.OpenApi.Model.VsanIscsiLUNRuntimeStatusTypeEnum
Defines iSCSI LUN runtime status type for iSCSI target service.  Possible values: - `Online`: LUN is loaded by vSAN iSCSI service successfully, if LUN runtime status is online, initiators can discover it after login to the target and it can provide IO service. - `Offline`: LUN is not loaded in kernel.      If LUN runtime status is offline, initiators can't discover it after login to the target. - `VsanIscsiLUNRuntimeStatusType_Unknown`
