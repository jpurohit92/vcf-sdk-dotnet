# Vcenter.ViJson.OpenApi.Model.VsanIscsiLUNStatusEnum
Defines iSCSI LUN status, supported values are Online, Offline.  Possible values: - `Online`: LUN is a configuration status, which is a desired state.      If LUN is online, initiators can discover the LUN after login to the target. - `Offline`: LUN is a configuration status, which is a desired state.      If LUN is offline, initiators can not discover the LUN after login to the target, all existing connections are closed. - `VsanIscsiLUNStatus_Unknown`
