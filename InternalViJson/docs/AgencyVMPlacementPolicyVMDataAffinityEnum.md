# Vcenter.ViJson.OpenApi.Model.AgencyVMPlacementPolicyVMDataAffinityEnum
Deprecated as of vSphere 9.0. Please refer to vLCM System VMs APIs.  Defines if the deployed VM is affinied to run on the same host it is deployed on.  Possible values: - `none`: Denotes no specific VM data affinity policy. - `soft`: Best effort is made the VM to run on the same host it is deployed on   as long as this does not impact the ability of the host to satisfy   current CPU or memory requirements for virtual machines on the   system.      NOTE: Currently not supported - i.e. the agency configuration is   considered as invalid.
