# Vcenter.ViJson.OpenApi.Model.VsanSnapHealthTypeEnum
It's used to declare the health types of the received stats from the vSAN SnapService Appliance.  Possible values: - `applianceHealth`: represent the health stats of the data protection appliance. - `pgSnapshotsHealth`: represent the snapshot health stats of the protection groups. - `vmSnapshotsHealth`: represent the snapshot health stats of the virtual machines. - `vmMembershipChanges`: represent the stats of VM membership changes. - `dpObjsInfo`: represent the list of dp objects(i.e.      pg namespace, cluster db namespace). - `generalHealth`: represent the health object which is consumable by vSAN Health - `VsanSnapHealthType_Unknown`: represent the value when the lower version client cannot recognize the enum value.
