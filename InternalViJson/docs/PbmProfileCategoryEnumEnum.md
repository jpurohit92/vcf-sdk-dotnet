# Vcenter.ViJson.OpenApi.Model.PbmProfileCategoryEnumEnum
The *PbmProfileCategoryEnum_enum* enumerated type defines the profile categories for a capability-based storage profile.  See *PbmCapabilityProfile*.  Possible values: - `REQUIREMENT`: Indicates a storage requirement.      Requirements are based on   storage capabilities. - `RESOURCE`: Indicates a storage capability.      Storage capabilities   are defined by storage providers. - `DATA_SERVICE_POLICY`: Indicates a data service policy that can be embedded into   another storage policy.
