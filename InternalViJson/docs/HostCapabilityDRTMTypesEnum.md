# Vcenter.ViJson.OpenApi.Model.HostCapabilityDRTMTypesEnum
Indicates the type of DRTM launch that occurred on the platform.  TPM attestation may be used to definitively determine the DRTM launch details, including the Measured Launch Environment (MLE).  Possible values: - `none`: No DRTM launch occurred. - `intelTxt`: Intel TXT DRTM launch occurred. - `amdSkinit`: AMD SKINIT DRTM launch occurred.    ***Since:*** vSphere API Release 9.1.0.0
