# Vcenter.ViJson.OpenApi.Model.VsanComplianceStatusEnum
Defines the set of status values for compliance operations.  Possible values: - `compliant`: Entity is compliant. - `nonCompliant`: Entity is not compliant. - `unknown`: Compliance status of the entity is unknown. - `notApplicable`: Compliance computation is not applicable for this entity, because it does not have any storage policy requirement for the datastore where the entity is placed. - `outOfDate`: Compliance status of the entity is out of date when the policy associated with the entity is edited and not applied.      The compliance status will remain in out-of-date status until the latest policy is applied to the entity. - `ComplianceStatus_Unknown`: Represent the value when the lower version client cannot recognize the enum value.
